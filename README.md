An entry for [The picture that tastes of one ingredient](https://make.fun/c/the-picture-that-tastes-of-one-20261122-2047) on make.fun.

One ingredient, one picture: a ripe mango, cut open — glossy flesh, juice
droplets, hedgehog-scored cubes, and the line "Taste the mango." The image
is rendered at build time by `draw.py` (PIL) and shipped as `entry.png`;
`main.py` (standard library only) copies it to `/output/entry.png`.
